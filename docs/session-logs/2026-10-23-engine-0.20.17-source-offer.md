## Recipe

`scripts/assemble-atum-engine-unsigned.sh` is the path-parameterized version of
the verified task recipe. It takes explicit source, build, Craft SDK, fresh
output, compiled revision, reviewed head and future-tag arguments. Optional
arguments retain both source archives, the implementation-equivalence receipt
and the Craft override.

The recipe:

- runs the SDK's `macdeployqt` with
  `-no-plugins -no-codesign -no-strip -always-overwrite`;
- manually stages only `OpenCloud_vfs_off.so`, Cocoa/minimal platform plugins
  and the Secure Transport TLS plugin;
- fixes the minimal plugin's FreeType dependency;
- removes and records absolute build/SDK `LC_RPATH` values;
- verifies the icon, production identity, arm64 closure, main minOS 14.0,
  bundled/system-only dependencies and absence of FinderSync;
- creates the canonical sorted file/link inventory twice and requires byte
  equality;
- proves hello/stop only against the exact pre-assembly production binary;
- records assembled runtime smoke as requiring a signature, because load
  command changes invalidate linker ad-hoc signatures; and
- retains source, Craft, compiler, profile, dependency and unsigned signature
  receipts beside the bundle.

There is no signing command, keychain lookup, install, notarization, deploy,
network publication or mutable owner path in the recipe. Successful ad-hoc
execution would still not be Developer ID evidence.

## Recipe change

`scripts/assemble-atum-engine-unsigned.sh` now rewrites absolute dependencies
of extra executables in `Contents/MacOS` (for example `atum-drivecmd`) to
`@loader_path/../Frameworks/<library>` when `macdeployqt` already bundled the
library. The block runs after `macdeployqt` and absolute-rpath removal, skips
the main `AtumDrive` executable, and records every rewrite in
`evidence/extra-executable-dependencies-rewritten.tsv`.

The new block matches the working build script except for the repository
`SCRIPT_DIR` line, which stays path-independent.
